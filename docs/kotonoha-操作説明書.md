# kotonoha 操作説明書

録音から議事録を作成し、会議資料とともに全員で記録と予定を共有するための説明書です。公開クラウド版を使う方を対象に、取り込みから編集、カレンダー、書き出しまでを説明します。

アプリを開く：[kotonoha 会議録ワークスペース](https://marugo-s.github.io/OEM/)

更新：2026年9月28日　集計・タグ・比較・通知の説明を追補（PDF版は第2版のまま）

## 最初の1件を作る

1. 共通ID「marugo」と、管理者から受け取ったパスワードでログインします。
2. 「新しい会議」を押し、「録音ファイル」で録音を選びます。録音が分かれている場合は、上から録音順に並べます。
3. 必要に応じて会議資料を追加し、「会議名」「開催日」「議事録の詳しさ」を入力します。
4. 「解析して議事録を作成」を押します。送信完了まで画面を開いたままにします。
5. 完成後に「議事録」「文字起こし」「アクション」を確認します。本文は「議事録を編集」、日程は「カレンダー」で修正できます。

> 最初に確認すること：録音は最大5ファイル・合計100 MB、資料は別枠で最大5ファイル・各10 MB・合計25 MBです。

## この説明書の見方

| ページ | 確認したいこと |
| --- | --- |
| 2 | ログイン、画面の見方、AIの接続設定 |
| 3 | 録音ファイルと会話テキストの取り込み |
| 4 | Excel・Word・PDFなどの会議資料の保存 |
| 5 | 議事録・文字起こしの編集と再生成 |
| 6 | カレンダー、予定の確認と手動変更 |
| 7 | 全員での共有、書き出し、削除、データの扱い |
| 8 | 困ったときの対処と利用前後のチェック |

録音済みのファイルの取り込みと、ブラウザーでの直接録音に対応します。録音中はアプリを開いたままにしてください。録音が終わってから文字起こしと議事録生成を行います。

## 集計・タグ・比較・通知（追補）

- API使用料では、文字起こし・議事録生成・タグ候補生成までを一連の作業として同じブロックの合計に含めます。タグ候補の再取得料金も含み、議事録の再生成は別ブロックになります。旧タグ履歴は同じ会議の直前の議事録生成に紐付け、「タグの紐付けは推定」と表示します。保存済み料金や月合計は変わりません。月をまたぐ処理は月別表示です。

- 「統計」のAIサマリーは「今月」「先月」「直近7日」「期間指定」から選びます。「先月」は日本時間の前月1日〜末日です。「期間指定」では開始日と終了日を入力します（両端を含み、終了日は今日まで）。表示された対象期間を確認して「AIサマリー生成」を押してください。対象期間に開催した解析完了の実際の会議だけを、編集済み本文・アクションの完了状態を使って整理します。見出し・会議ごとの小見出し・短い段落・箇条書き・太字で表示します。結果は画面内のみで保存されません。対象が多すぎる場合は期間を短くしてください。
- アプリを開いている間に議事録が完成すると、AIタグ候補のポップアップが自動で開きます。複数の候補にチェックし、「選んだタグを保存」で議事録に紐付けます。既存タグは残ります。「今は付けない」や閉じる操作では保存しません。複数会議が完了した場合は順番に表示します。候補取得に失敗しても議事録は完成済みで、必要な場合だけ「候補を再取得」を押します。詳細の「タグ候補を開く」で再表示できます。同じ画面内では候補を再利用し、再読み込み後は再生成になります。画面を閉じている間に完了した会議や過去の会議は手動で候補を開いてください。保存タグは全員に共有され、同時編集は最後の保存が優先です。手動作成した未使用の候補名だけはブラウザー内の保存です。
- AIサマリー・タグ提案には、接続設定のOpenAIキーと議事録モデルを使います。「API使用料」で種類と概算料金を確認できます。通信中断時には結果・料金を取得できない場合があります。
- 「会議比較」は2〜5件を選択できます。選択後も会議の追加・解除が可能です。
- 時間比較・総録音時間には分割音声の合計時間を表示します。時間が分からない会議は「未取得」と表示し、平均・合計から除きます。保存済みの分割音声にも再解析なしで適用されます。
- 一括Markdownは保存済みの議事録本文を含みます。ICSは会議の開催日を終日予定として書き出します。抽出された個々の予定の自動同期ではありません。
- 接続設定でブラウザー通知を許可すると、アプリを開いている間、カレンダーの確定した期限超過を同じタブで1回通知します。アクションと内容・担当者が一致する完了済み項目は除きます。アプリを閉じている間の通知や、すべての端末での通知は保証されません。
- 音声の変換・必要な再圧縮は取り込み時に行います。保存済み音声を後から最適化する機能はありません。

# 1 ログインと画面の見方

## ログインする

1. アプリのURLをブラウザーで開きます。
2. 共通ID「marugo」と、管理者から受け取ったパスワードを入力します。個別ユーザー登録やSupabaseアカウントは不要です。
3. ログイン後は「共有ワークスペース」が開きます。スマートフォンなどで左メニューが見えないときは、左上のメニューボタンを押します。

ログインの有効期限が切れた場合は、再度ログインします。ログインに繰り返し失敗して制限が表示された場合は、15分ほど待ってからIDとパスワードを確認してください。共用端末では、利用後に「ログアウト」を押します。

## 主な画面

| メニューやボタン | できること |
| --- | --- |
| 新しい会議 | 録音または会話テキストと、必要な資料を取り込む |
| すべての会議 | 会議を検索して開く。完了・処理中で絞り込む |
| カレンダー | 予定・期限を月間または一覧で見て、手動変更する |
| アクション | 会議から抽出した作業、担当、期限を確認し、完了にする |
| 使い方ガイド | アプリ内の簡単な操作案内を読む |
| 接続設定 | 共有のAPIキーと議事録の解析モデルを設定する |

## 初回のAI設定

管理者など設定を担当する方が左メニューの「接続設定」を開き、OpenAI APIキーを入力します。左メニューが画面に収まらない場合はメニュー内をスクロールできます。会話解析・議事録には「GPT-6 Astra」「GPT-6 Sol」「GPT-6 Luna」から選びます。Lunaは低コストですが、複雑な議論の整理にはAstraやSolも比較してください。文字起こしは「GPT Transcribe」または「Gemini 3.5 Transcribe」から選択でき、Geminiを使う場合はGemini APIキーも入力して「設定を保存」を押します。

左メニューの「API使用料」で対象月を選び、「この月の為替レート」に1ドルあたりの円額を入力して「レートを保存」を押すと、解析1回ごとの概算料金と月合計が円で表示されます。レートはこのブラウザーに月ごとに保存され、他の端末には共有されません。会議の行を開くと、文字起こし・議事録生成の各API呼び出し日時、モデル、入力・出力トークン、音声時間、料金を確認できます。音声を分割しても同じ解析にまとめ、再生成は別の解析として表示します。解析IDのない旧履歴は会議と処理順から推定してまとめます。月をまたぐ解析は月別に分かれます。履歴はこの機能を導入した後の利用からで、会議を削除しても残ります。「推定」は録音時間などから料金を計算した行です。確定した請求額、無料枠、税、実際の為替は各社の請求画面で確認してください。

「APIキー設定済み」なら、通常は入力し直す必要はありません。モデルだけ変えるときは、キー欄を空欄のまま保存できます。設定保存だけではモデルが利用できるかの確認は完了せず、実際の解析時に確認されます。APIの利用枠・モデル権限が必要です。

> 設定も全員共通です。APIキーやモデルの変更は、ほかの人の解析にも影響します。設定を変更する前に、チーム内で確認してください。

操作を試すだけなら「サンプルを開く」が使えます。サンプルは架空の固定データで、実際のAI解析は行いません。

# 2 録音や会話を取り込む

## 録音ファイルから作る

1. 「新しい会議」または「録音ファイルを取り込む」を押します。
2. 「録音ファイル」タブの「ファイルを選択」から録音を選びます。パソコンではファイルを枠へドロップしても取り込めます。
3. 複数の録音がある場合は「ファイルを追加」で選び、上下の矢印で録音順に並べます。不要なものは解除ボタンで選択から外します。
4. 必要なら「会議の添付資料」に資料を追加します。「会議名」「開催日」「議事録の詳しさ」を入力し、「参加者」は必要に応じて記入します。
5. 「解析して議事録を作成」を押します。音声・資料の送信が終わるまでは、画面を閉じたり再読み込みしたりしないでください。

| 入力内容 | 対応形式や上限 |
| --- | --- |
| 録音 | 最大5ファイル、合計100 MB（100,000,000バイト） |
| 主な音声形式 | AAC、MP3、M4A、WAV、OGG、FLAC。MPEG・MPGAも対応 |
| 動画形式 | MP4、M4V、MOV、MKV、WebM、MTS・M2TS・TS、3GP。音声だけを取り出して使い、映像は送信しない |
| 会話テキスト | 貼り付け・音声の文字起こし結果ともに合計10万文字まで |
| 議事録の形式・詳しさ | 要約版／標準版／詳細版（背景も詳しく） |

## 録音が途中で分かれた場合

同じ会議の録音を、前半・後半の順に並べてください。大きな録音はアプリが自動分割し、録音順に文字起こしして1つの議事録にまとめます。AACは対応する形式であればM4Aへ自動変換されます。

動画のDolby音声（AC-3など）やカメラのPCM音声は、ブラウザー内で会話向けの軽い音声に変換して送信します。DTSなど変換できない音声やAVI・WMVはエラーになるため、AAC音声のMP4などに書き出してください。

音声ファイル自体を1本に合成する機能ではありません。録音が切れた間の発言は補完せず、重複部分も自動削除しません。「文字起こし」タブでは、保存された分割単位で録音を切り替えて再生できます。

## 文字起こし済みテキストから作る

「文字起こし済みテキスト」タブで「会話テキスト」に貼り付け、会議名などを入力して「解析して議事録を作成」を押します。音声の文字起こし処理は行わず、会話解析から始めます。資料を一緒に保存することもできます（解析には使いません）。

> 「開催日」は会議をした日です。「明日」などの日付を判断する基準になるため、録音をアップロードする日と取り違えないでください。

送信完了後は、完了した処理が保存されます。画面を閉じても、残りの文字起こしと議事録作成はサーバーで自動的に続きます（約1分ごとに進行を確認します）。画面を開いたままにすると、より早く完成します。

# 3 会議資料を保存する

## 対応資料と容量

| 資料 | 対応するファイル |
| --- | --- |
| PDF | .pdf |
| Excel | .xlsx、.xls |
| Word | .docx、.doc |
| PowerPoint | .pptx、.ppt |
| 表やテキスト | .csv、.txt |

資料は1会議につき最大5ファイル、1ファイル10 MBまで、合計25 MBまでです。録音の100 MBとは別枠です。パスワード保護は解除してください。資料だけを取り込んで会議を作ることはできません。

> 添付資料は会議の参考資料として保存・共有するためのものです。AIには送信せず、文字起こしや議事録の解析には使いません。資料の追加・解除で議事録を再生成する必要はありません。

## 新しい会議に付ける

「新しい会議」の「会議の添付資料」に資料をドラッグ＆ドロップするか、「資料ファイルを選択」を押します。録音または会話テキストと資料を選び、「解析して議事録を作成」を押すと、資料を保存してから会話を解析します。

資料の送信時には選択したファイルの内容を照合します。名前の内部表記だけが異なる場合でも、同じ資料であれば取り込めます。

## 作成済みの会議に後から付ける

1. 会議を開き、「添付資料」タブの枠に資料をドラッグ＆ドロップするか、「ファイルを選択」を押します。ほかのタブを表示中に会議画面へドロップした場合も、「添付資料」タブに切り替わって選択されます。
2. 「選択した資料を保存」を押します。

## 保存した資料を使う

原本は「添付資料」タブの「ダウンロード」で取得できます。「関連付けを解除する」は資料一覧から外す操作です。保存ファイルは保持され、管理者が復元できます。

以前の版で資料と照合して作成した議事録には「添付資料との照合」が残っています。再生成すると、会話だけから作り直した議事録に置き換わります。

# 4 議事録を確認して編集する

## 会議画面のタブ

会議の内容は、タイトル下のタブで切り替えます。「アクション」「予定・期限」「添付資料」の横の数字は件数です。

| タブ | 確認できること |
| --- | --- |
| 議事録 | 要約、議題、決定事項、作業と期限、継続検討事項 |
| 文字起こし | 会話の全文と録音 |
| アクション | 作業の担当・期限。チェックで完了・未完了を切り替える |
| 予定・期限 | この会議から抽出した予定と期限。行か「カレンダーで確認」を押すとカレンダーを開く |
| 添付資料 | 保存した資料のダウンロード、資料の追加・解除 |

右側には「会議のポイント」と、「決まったこと」「次のアクション」の件数を表示します。「決まったこと」を押すと決定事項を開閉し、「次のアクション」を押すと「アクション」タブに移ります。Geminiで完了しなかった録音をGPT Transcribeに切り替えた場合は、タイトル下の日付の並びに「文字起こし：GPT Transcribe（Gemini失敗のため切替）」と表示します。

AIの出力には誤りがあり得ます。特に人名、金額、日付、担当者、合意したかどうかを確認してください。通常の文字起こしには話者名や発言時刻は付かず、参加者名との対応も推測しません。

## 議事録本文を手動で直す

会議名を変えるには、詳細画面のタイトル横「名前を変更」、または左メニュー「最近の会議」の鉛筆ボタンを押します。新しい名前を保存すると、一覧・詳細・API使用料の会議名・書き出し時のファイル名に反映され、共有中の全員にも表示されます。議事録本文の先頭が旧会議名の見出しなら、その見出しだけ新しい名前に合わせます。旧会議名と一致しない見出し・本文は変更しません。処理中の会議は完了後に変更してください。

1. 「議事録」タブで「議事録を編集」を押します。
2. 本文を修正・追記します。見出しは「## 見出し」、箇条書きは「- 内容」の形式で書けます。
3. 「保存」を押します。保存した本文は、ログインした全員に共有されます。

「取消」は編集をやめる操作です。未保存の変更がある場合は、破棄の確認が出ます。本文編集中はほかの画面への移動が制限されます。本文は最大15万文字です。

## 修正する場所の違い

| 直したい内容 | 操作と反映先 |
| --- | --- |
| 議事録の文章 | 「議事録を編集」→「保存」。本文だけが変わる |
| 会話の認識間違い | 「文字起こしを編集」→「保存」。議事録への反映は再生成が必要 |
| 予定の日付や担当 | カレンダーの「予定を編集」。議事録本文は変わらない |
| 作業の完了状態 | 「アクション」のチェック。再生成するとリセットされる |

本文と、AI抽出の要点・決定事項・アクション、カレンダーは別々に管理されます。本文の日時を書き換えただけでは、予定表の日付は変わりません。画面の「会議のポイント」「決まったこと」はAI抽出結果です。

## 認識の修正を再解析する

作成後も「詳しさを変えて再生成」を押し、確認画面で「要約版／標準版／詳細版（背景も詳しく）」を選べます。「再生成する」で、選んだ形式・現在の文字起こし・接続設定のモデルで再解析します。保存済みの文字起こしは再利用し、未完了の音声のみ文字起こしを行います。必要なら先に「文字起こし」タブで本文を修正・保存してください。詳しくする場合も会話にない内容を補うものではなく、添付資料は解析に使いません。キャンセル時は形式も本文も変更しません。編集済み議事録とアクションの完了状態は上書きされます。既存タグとカレンダーの手動変更は保持します。

### 3つの基本形式と柔軟な構成

「要約版」は主な方針・決定・次の対応を短く、「標準版」は必要な背景・経緯を添え、「詳細版」は理由・異論・検討の経緯も詳しく残します。初期選択は従来どおり詳細版です。基本形式だけを選んでも会議名・参加者は上書きしません。

本文は基本情報、内容要旨、決定事項、議題別の内容、次の対応（担当・期限の表）、継続検討・確認事項、次回会議を基盤にします。会議内容に合わせて項目や分量を変え、該当しない項目は省略します。次回会議は会話に明確な言及がある場合のみ記載します。サンプルのページ数に固定せず、要約でも重要な担当・期限を落とさず、詳細でも水増ししません。既存の議事録は自動変更されず、新規作成または再生成から適用されます。

> 再生成すると編集済み本文とアクションの完了状態は上書きされます。予定の手動変更は残りますが、元の予定が変わった場合は要確認になります。

# 5 カレンダーと予定の手動変更

## 予定を探す

左メニューの「カレンダー」を開きます。「月間」と「予定一覧」を切り替え、前後の矢印や年月欄で表示月を変えられます。「今日」で当月へ戻ります。月間表示では日付を選ぶと、その日の予定の時間・場所・担当者が表示されます。

予定名・会議名・場所・担当者で検索でき、種類と状態でも絞り込めます。予定の会議名を押すと元の議事録へ移動し、「会議・資料の根拠を確認」で元の発言や資料を確認できます。サンプル会議は共有カレンダーに含めません。

| 状態 | 意味と確認すること |
| --- | --- |
| 確定 | 会話で合意した予定として抽出、または手動設定したもの。AIの判定は原文と照合する |
| 予定案 | 候補・提案、または資料にだけ書かれた予定。会議で確定したとは限らない |
| 要確認 | 日付や合意が不明、旧議事録の候補、再解析後の変更など。内容を確認して保存する |

## 予定を変更する

予定カードの「削除」は1件だけカレンダーから除外します。複数件は画面上部の「選択して一括削除」からカードを選びます。「表示中を全選択」や、日付未定欄の「このN件を選択」も使えます。確認画面で対象を見てから実行してください。画面下部の「削除済みの予定」から元に戻せます。会議録・文字起こし・資料は消えず、AIの利用料も発生しません。削除は全員に共有され、同じ予定は再生成後も非表示です。ただしAIが別の内容として抽出した場合は新しい候補として現れることがあります。

1. 対象の予定の「予定を編集」を押します。
2. 予定名、種類、状態、開始日・終了日、開始・終了時刻、場所、担当者を変更します。
3. 元の記録を照合して「予定を保存」を押します。全員のカレンダーへ反映され、「手動変更」と表示されます。編集だけではAI利用料は発生しません。

単日の予定は終了日を空欄にします。時刻が決まっていなければ時刻欄も空欄のままで構いません。日をまたぐ場合は終了日を指定します。期間の終了日は含み、時刻は日本時間で表示します。

## 日付未定や以前の議事録の扱い

「来週まで」「月末」など1日に特定できない表現は、画面下の「日付を確認する予定」に表示します。日付が決まったら「予定を編集」で入力し、状態を選んで保存してください。日付を空欄にする場合は状態を「要確認」にし、終了日と時刻も空欄にします。

以前の議事録は決定事項や期限から候補を表示し、すべて要確認として扱います。年のない月日は会議の年を補った候補なので、年をまたぐ予定は特に確認してください。

> 手動変更は再生成後も残ります。「元の抽出結果に戻す」で変更を取り消せますが、再解析で元の予定がなくなっている場合、その手動予定はカレンダーから消えます。外部カレンダーへの自動同期はありません。通知の条件は冒頭の追補をご確認ください。

# 6 共有と書き出しとデータの管理

## 全員に同じ内容が見える

ログインした全員が同じ会議・音声・資料・議事録・カレンダーを利用します。編集や削除も全員共通です。ほかの人の変更は通常約10秒ごとに反映されますが、編集中は更新を止めています。

同じ本文や同じ予定を同時編集すると、最後に保存した内容が優先されます。大きな修正の前に、ほかの人が編集していないか確認してください。利用者ごとの閲覧制限や個別の変更履歴はありません。

## 記録を書き出す

会議を開き、右上の「書き出す」から選びます。

| メニュー | 保存できる内容 |
| --- | --- |
| 議事録（Markdown） | 現在の議事録本文。手動編集した内容も含む |
| 文字起こし（テキスト） | 会話の全文 |
| すべてのデータ（JSON） | 解析結果や予定の手動変更などの記録データ。音声・資料の実ファイルは含まない |
| 印刷・PDFに保存 | ブラウザーの印刷画面で確認し、プリンターやPDF保存を選ぶ |

添付資料の原本は、「添付資料」タブの「ダウンロード」から別に保存します。カレンダーで変更した日付は議事録本文へ自動反映されないため、提出用の議事録にも必要なら本文を別途編集してください。

## 会議を削除する

会議を開き「会議を削除」を押し、確認画面で「ゴミ箱へ移動」を選びます。通常の会議は一覧から非表示になり、音声・資料は保持されます。アプリ内の復元ボタンはないため、復元や完全消去は管理者に依頼します。

取り込み途中の会議を削除する場合は例外です。送信済みの未完了音声は完全に削除されるため、再取り込みに使う元の録音ファイルを残してください。

## 保存場所と費用と秘密情報

会議の記録はSupabaseの会議録専用領域へ、音声・資料は非公開の保存先へ保管されます。OpenAIとGeminiのAPIキーはこのアプリ専用のサーバー側で別々に暗号化保存され、画面へ再表示されません。共通パスワードやAPIキーを、議事録・資料・説明書へ記載しないでください。

GPT-4o文字起こしでは音声をOpenAIへ送信します。Gemini文字起こしでは音声をGoogleへ一時送信し、完了後に一時ファイルの削除を要求します。Geminiで文字起こしが完了しなかった録音は自動でGPT Transcribeに切り替え、その録音の音声はOpenAIへ送信します（会議の詳細に表示されます）。会話テキスト・議事録生成はOpenAIへ送信し、結果取得のためのデータもOpenAI側に保存します。添付資料はAIへ送信しません。機密資料は社内ルールに従って扱ってください。キーと利用枠はワークスペース共通です。閲覧や手動編集そのものでは新しいAI解析を依頼しません。ただし、未完了の取り込みがある場合は、画面を開くと残りの処理が再開します。

# 7 困ったときと確認チェック

## よくある状況と対処

| 状況 | 確認すること・操作 |
| --- | --- |
| ログインできない | ID・パスワードを確認。有効期限切れなら再ログイン。回数制限の表示があれば15分ほど待つ |
| 作成ボタンを押せない | APIキーが設定済みか、録音または空でない会話テキストが選ばれているか確認 |
| 容量や件数で受け付けない | 録音は5本・合計100 MB、資料は5個・各10 MB・合計25 MB。超える場合は内容を整理して会議を分ける |
| AACなどを読み込めない | 圧縮方式が非対応、または破損の可能性。元のアプリでM4A・MP3・WAVに書き出し直す |
| 取り込み途中で止まった | 送信中の画面を確認。送信を中断した場合は、途中の会議を削除し元ファイルから取り込み直す |
| 解析でエラーが出る | 表示内容を確認し、APIキー・利用枠・モデル権限を管理者に確認。同時AI処理は全員合わせて2件まで。原因を解消して「再試行」 |
| 画面を閉じた後に処理が進まない | 通常は数分以内にサーバーで再開する。長時間進まない場合はアプリを開いて状態を確認し、管理者にサーバーの定期処理の設定を確認。結果を取得できなければ保存済みテキストから再生成 |
| 資料を追加したのに議事録が変わらない | 添付資料は保存専用で、AI解析には使わない。資料の内容は議事録本文に手動で追記する |
| 本文を直しても予定が変わらない | 本文とカレンダーは別管理。「予定を編集」で日付などを変更する |
| 日付がない・違う | 検索条件と表示月、「日付を確認する予定」、元の会議日を確認。AIの判断を照合し、手動で修正する |

## 利用前後のチェック

- 取り込み前：AIへ送信してよい内容か、社内ルールと参加者への案内を確認した。
- 取り込み前：録音の順番・容量・件数・会議日を確認し、必要な資料を用意した。
- 共有前：人名・金額・日付・担当・決定と提案を原文と照合し、本文と予定をそれぞれ保存した。
- 再生成前：必要な本文を書き出し、編集内容の上書きを理解した。
- 終了時：必要な記録を保存し、共用端末ではログアウトした。

操作が分からないときは、会議名・発生した操作・エラー文を管理者に伝えてください。パスワードやAPIキーは送らないでください。
